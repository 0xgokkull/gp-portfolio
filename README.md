# GP Portfolio

A React + Tailwind portfolio site, now running on Vite.

## Scripts

- `npm run dev` or `npm start`: Start the Vite dev server.
- `npm run build`: Build production assets.
- `npm run preview`: Preview the production build locally.
- `npm run test`: Run tests once with Vitest.
- `npm run test:watch`: Run tests in watch mode with Vitest.

## Development

1. Install dependencies:

```bash
npm install
```

2. Start the app:

```bash
npm run dev
```

3. Open the local URL shown in terminal (usually `http://localhost:5173`).
